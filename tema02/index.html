¿Por qué casi todos los navegadores comparten motor? El hecho de compartir motor facilita la implementación de estándares web, de esta manera se puede facilitar el uso de la programación web y reduce el trabajo necesario para mantener un navegador. La mayoría de los navegadores comparten Chromium, por lo que blink y V8 ofrece una base tecnológica común y desarrollada. Esto hace que los principales navegadores que quedan fuera son Firefox, y Safari. Por lo tanto, una página puede comportarse de forma ligeramente diferente según el navegador. Usar estándares web, comprobando la compatibilidad de las funciones que se utilicen y evitar depender de característias exclusivas de un motor son buenas prácticas a realizar por un desarrollador web, consiguiendo una web más compatible, accesible y consistente para diferentes usuarios y dispositivos.
